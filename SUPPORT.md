# Support

## Community Support

For general questions and usage help:

- GitHub Issues
- GitHub Discussions (recommended)

## Bug Reports

Please include:

- PaymentKit version
- Node.js version
- Gateway used (Stripe / PayPal)
- Logs or error messages
- Minimal reproduction steps

## Feature Requests

Open an issue and clearly describe:

- The problem you’re solving
- Why it belongs in PaymentKit
- Possible alternatives
