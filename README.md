# @ciscode/PaymentKit

Unified payment package for NestJs with a single API over Stripe, Paypal and Adyen. 

## Status 

Preparing MVP Release (12/12/2025)

## Installation  

```bash 
npm install @ciscode/paymentkit
``` 

## Usage 

API is under active design. Initial version will expose a PaymentKitModule and PaymentService.
